# 業界レーダー — 就活生のための企業比較サイト

IT・通信／総合商社／自動車／メガバンク・金融の主要29社を、時価総額・売上・純利益・ROE などのランキングとグラフで比較できる静的サイトです。ダーク＆ネオンの見た目で「眺めて楽しい」ことを重視しています。

- **フレームワーク**: Next.js 16（App Router, TypeScript, `output: "export"` による静的書き出し）
- **グラフ**: Apache ECharts 6（必要なチャートだけを読み込み）
- **スタイル**: Tailwind CSS 4、フォントは `@fontsource`（Noto Sans JP / Space Grotesk）を同梱

## ページ構成

| パス | 内容 |
|---|---|
| `/` | 掲載29社の時価総額合計（カウントアップ）、業界カード、時価総額マップ（ツリーマップ）、全業界TOP10（指標切替）、業界の規模くらべ、ROE×時価総額の散布図 |
| `/industry/[id]/` | 業界KPI、No.1企業、業界内ランキング（6指標）、時価総額シェア、規模×収益性バブル、5期推移（1社を強調）、並べ替え可能な指標表 |
| `/company/[code]/` | 企業KPI（PER・PBR含む）、業界内順位バッジ、5期の売上・純利益、5軸スコア（業界平均と比較）、同業他社の中での位置 |
| `/compare/?c=7203,8058,8306` | 最大3社を横並び比較（レーダー・数値表・指標別グラフ）。URLで比較を共有可能 |
| `/about/` | 出典・照合した数値・用語の定義・注意事項 |

## データ

- `src/data/companies.json` — 企業ごとの財務（百万円）。5期分の売上・純利益、最新期の自己資本、時価総額・株価。
- `src/data/meta.json` — 時価総額の基準日、出典、照合した数値の一覧。

出典と確認方法:

1. 売上・純利益・自己資本は Financial Modeling Prep の財務データ（Bigdata.com 経由）。
2. 主要企業の直近期の売上・純利益は、決算短信・決算報道と照合して一致を確認（一覧は `/about/` に掲載）。
3. FMP の「営業利益」は IFRS 企業で決算短信と食い違う例があった（NRI・ソフトバンク・NTT）ため、利益指標は純利益（親会社株主に帰属）に統一。
4. 金融機関の売上相当（経常収益等）は決算短信・報道値を使用し、最新期のみ掲載。
5. 時価総額・株価は 2026年11月5日終値（東証）。
6. 平均年収・従業員数は、出典ごとに定義（提出会社単体か連結か）がそろわないため未掲載。JSON に `avgSalary` / `employees` の項目だけ用意してあります。

### データを更新するとき

`companies.json` の該当企業の値を書き換え、`meta.json` の `marketCapAsOf` / `updatedAt` を更新します。ランキング・業界合計・ROE などの指標はビルド時に自動計算されます。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # out/ に静的サイトを書き出し
npm run lint
```

## 公開

`npm run build` で生成される `out/` を任意の静的ホスティングに置くだけで動きます。

- **Vercel / Netlify / Cloudflare Pages**: そのままデプロイ可能（ビルドコマンド `npm run build`、出力 `out`）。
- **GitHub Pages**（`https://<user>.github.io/company_analysis/`）: サブパスで配信されるため、ビルド時に `NEXT_PUBLIC_BASE_PATH=/company_analysis npm run build` を指定してください。

## 配色について

業界色（IT=シアン、商社=アンバー、自動車=マゼンタ、金融=グリーン）と比較ページの3色は、色覚シミュレーションの検証スクリプトでダーク背景に対する判別性を確認済みです。色だけに頼らず、企業名・業界名のラベルを常に併記しています。
