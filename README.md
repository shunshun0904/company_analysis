# 業界レーダー — 就活生のための企業比較サイト

IT・通信／総合商社／自動車／メガバンク・金融の主要29社を、**平均年収・初任給・大学別の就職者数・社長の出身大学**、そして業績や会社の規模まで、ランキングとグラフで比べられる静的サイトです。ダーク＆ネオンの見た目で「眺めて楽しい」ことを重視しています。

- **フレームワーク**: Next.js 16（App Router, TypeScript, `output: "export"` による静的書き出し）
- **グラフ**: Apache ECharts 6（必要なチャートだけを読み込み）
- **スタイル**: Tailwind CSS 4、フォントは `@fontsource`（Noto Sans JP / Space Grotesk）を同梱

## ページ構成

| パス | 内容 |
|---|---|
| `/` | 平均年収トップ（カウントアップ）、全業界TOP10（平均年収・初任給・平均年齢・時価総額・純利益）、就職者が多い大学、社長の出身大学、業界カード、平均年収×平均年齢マップ、会社の規模マップ |
| `/industry/[id]/` | 平均年収・初任給の中央値、No.1企業、業界内ランキング（9指標）、業界×大学のヒートマップ、年収×年齢マップ、業績の推移、並べ替えできる一覧表 |
| `/company/[code]/` | 平均年収・初任給（条件・出典つき）・平均年齢・勤続年数・従業員数、大学別の就職者数、社長と出身大学、規模と業績、会社の強み（5軸）、同業比較 |
| `/university/?u=早稲田大学` | 大学を選ぶと、掲載企業への就職者数と、その大学出身の社長がわかる |
| `/compare/?c=7203,8058,8306` | 最大3社を横並び比較（レーダー・数値表・指標別グラフ）。URLで比較を共有可能 |
| `/about/` | 出典・照合した数値・用語の定義・注意事項 |

## データ

`src/data/companies.json`（企業ごと）と `src/data/meta.json`（基準日・出典）にまとめています。

| 項目 | 出典 | 備考 |
|---|---|---|
| 平均年収・平均年齢・平均勤続年数・従業員数 | 有価証券報告書「従業員の状況」（EDINET原本、2026年3月期／楽天は2025年12月期） | 提出会社の値。持株会社（NTT・金融各社）はその旨を表示し、有報に主要子会社の値があれば併記 |
| 初任給 | マイナビ・リクナビの各社掲載値 | 2027年卒の掲載値を優先。年度・コース・固定残業代の有無・出典URLを企業ごとに保持。LINEヤフーは確認できず |
| 大学別の就職者数 | 大学通信「企業ごとの大学別就職者数」（2025年春） | 各社の上位に掲載された大学のみ。豊田通商・東京海上日動は数値を取得できず、ホンダは大学側ページの値 |
| 社長・出身大学 | 社長は有報の役員の状況で特定。学歴は公式資料・大学資料・報道 | 29人中22人を確認（報道1件のみの場合は表示で区別）。取締役全員は有報に学歴がなく未対応 |
| 売上・純利益・自己資本（5期） | Financial Modeling Prep（Bigdata.com 経由） | 主要値を決算短信・報道と照合。営業利益はIFRS企業で食い違いがあったため不使用 |
| 時価総額 | Bigdata.com（2026年11月5日終値） | |

### データを更新するとき

`companies.json` の該当企業の値を書き換え、`meta.json` の基準日を更新します。ランキング・中央値・業界合計・大学別の集計はビルド時に自動計算されます。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # out/ に静的サイトを書き出し
npm run lint
```

## 公開

`npm run build` で生成される `out/` を任意の静的ホスティングに置くだけで動きます。

- **Vercel / Netlify / Cloudflare Pages**: そのままデプロイ可能（ビルドコマンド `npm run build`、出力 `out`）。
- **GitHub Pages**（`https://<user>.github.io/company_analysis/`）: サブパスで配信されるため、ビルド時に `NEXT_PUBLIC_BASE_PATH=/company_analysis npm run build` を指定してください。

## 配色について

業界色（IT=シアン、商社=アンバー、自動車=マゼンタ、金融=グリーン）と比較ページの3色は、色覚シミュレーションの検証スクリプトでダーク背景に対する判別性を確認済みです。色だけに頼らず、企業名・業界名のラベルを常に併記しています。
