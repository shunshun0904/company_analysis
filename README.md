# 業界レーダー — 就活生のための企業比較サイト

IT・通信／総合商社／自動車／メガバンク・金融の主要29社を、**平均年収・初任給・大学別の就職者数・社長の出身大学・世間ウケ（結婚相手・親・就活生からの人気）・モテる会社**、そして業績や会社の規模まで、ランキングとグラフで比べられる静的サイトです。ダーク＆ネオンの見た目で「眺めて楽しい」ことを重視しています。

- **フレームワーク**: Next.js 16（App Router, TypeScript, `output: "export"` による静的書き出し）
- **グラフ**: Apache ECharts 6（必要なチャートだけを読み込み）
- **スタイル**: Tailwind CSS 4、フォントは `@fontsource`（Noto Sans JP / Space Grotesk）を同梱

## ページ構成

## データ

`src/data/companies.json`（企業ごと）、`src/data/popularity.json`（世間ウケ・モテる会社の調査順位）、`src/data/meta.json`（基準日・出典）にまとめています。

| 項目 | 出典 | 備考 |
|---|---|---|
| 平均年収・平均年齢・平均勤続年数・従業員数 | 有価証券報告書「従業員の状況」（EDINET原本、2026年3月期／楽天は2025年12月期） | 提出会社の値。持株会社（NTT・金融各社）はその旨を表示し、有報に主要子会社の値があれば併記 |
| 初任給 | マイナビ・リクナビの各社掲載値 | 2027年卒の掲載値を優先。年度・コース・固定残業代の有無・出典URLを企業ごとに保持。LINEヤフーは確認できず |
| 大学別の就職者数 | 大学通信「企業ごとの大学別就職者数」（2025年春） | 各社の上位に掲載された大学のみ。豊田通商・東京海上日動は数値を取得できず、ホンダは大学側ページの値 |
| 社長・出身大学 | 社長は有報の役員の状況で特定。学歴は公式資料・大学資料・報道 | 29人中22人を確認（報道1件のみの場合は表示で区別）。取締役全員は有報に学歴がなく未対応 |
| 世間ウケ | リスクモンスター「この企業に勤める人と結婚したいランキング」第15回（2025年6月）・「お子さん／お孫さんに勤めてほしい企業」第14回（2026年4月）、マイナビ・日経「2027年卒大学生就職企業人気ランキング」文系総合・理系総合（2026年4月） | 公表トップ100の順位をそのまま掲載（`src/data/popularity.json`）。銀行・証券・保険は調査上の名前（三菱UFJ銀行など）の順位。最新の「結婚したい」第16回（2026年10月）は上位8位のみ公開のため別枠 |
| モテる会社 | リスクモンスター「この企業に勤める人と結婚したいランキング」第15回の男女別（2025年6月）・「合コンしたいと思う企業ランキング」第3回（2019年12月） | 男女別は上位19〜20社のみ公表。合コンの調査は最新版が2019年。最新の男女別（第16回、2026年10月）は上位4〜5位のみ公開のため別枠 |
| 売上・純利益・自己資本（5期） | Financial Modeling Prep（Bigdata.com 経由） | 主要値を決算短信・報道と照合。営業利益はIFRS企業で食い違いがあったため不使用 |
| 時価総額 | Bigdata.com（2026年11月5日終値） | |

### データを更新するとき

`companies.json` の該当企業の値を書き換え、`meta.json` の基準日を更新します。ランキング・中央値・業界合計・大学別の集計はビルド時に自動計算されます。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # out/ に静的サイトを書き出し
npm run lint
```

## 公開

### GitHub Pages（設定済み）

`main` ブランチに push すると、`.github/workflows/deploy-pages.yml` がビルドして `https://shunshun0904.github.io/company_analysis/` に公開します。Actions タブの「Deploy to GitHub Pages」から手動実行もできます。

公開が失敗するときは、GitHub のリポジトリ設定で次を確認してください。

1. **Settings → Pages → Build and deployment → Source** が「GitHub Actions」になっている
2. 「environment protection rules」で止まる場合は、**Settings → Environments → github-pages → Deployment branches** に `main` が含まれている

サブパス（`/company_analysis/`）で配信するため、ワークフローではビルド時に `NEXT_PUBLIC_BASE_PATH=/company_analysis` を指定しています。手元で同じものを作るときは `NEXT_PUBLIC_BASE_PATH=/company_analysis npm run build` です。

### そのほかの静的ホスティング

`npm run build` で生成される `out/` を置くだけで動きます。Vercel / Netlify / Cloudflare Pages ならビルドコマンド `npm run build`、出力 `out` でそのままデプロイできます（ルート配信なので `NEXT_PUBLIC_BASE_PATH` は不要）。

## 配色について

業界色（IT=シアン、商社=アンバー、自動車=マゼンタ、金融=グリーン）と比較ページの3色は、色覚シミュレーションの検証スクリプトでダーク背景に対する判別性を確認済みです。色だけに頼らず、企業名・業界名のラベルを常に併記しています。
